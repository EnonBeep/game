# Problem
    People who enojoy cozy simluators can't enjoy the game as a cat who is running a cafe buisness.There are not a lot of simulators that you can play in short sessions with simpel goals. An easy,short-session game themed around a cat cafe would fill that gap.

# Initial Requirments
    R1: Game must allow player to control a cat who is the barista.
    R2: Has to generate cat custemers who visit the cafe and order
    R3: Allow the players to prepare drink by selecting ingredients
    R4: must compare the prepared drink to custemers request
    R5: If correct reward the player w coins, if wrong no coins
    R6: Should save the players progress locally and be avaible when game reopened.

# Round 2 Requiremnts
    R7: The game runs in a web browser, served from the players computer with one command.
    R8: Add a menu with the recipies for each drink.
